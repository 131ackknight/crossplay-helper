How to read the answer

  • In this solver's list. The solver can play it. For Crossplay, it is also not one of the 182 words the Times cut.
  • Not playable in Crossplay. The Times removed it from NWL2023. Switch the game to Scrabble if you want to know whether this file still has it.
  • Not in this solver's list. Crossplay may still accept it. The miss means the word is one of the 17,991 this file does not have, or it is not a word at all.

Hooks under a yes are other words in this same list, one letter longer. They follow the game you picked, so a Crossplay cut will not show up as a hook.
